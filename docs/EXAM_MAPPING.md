# University practical exam ↔ Gradient labs

The April/May 2026 CS3491 practical papers (SET 1 / SET 2) contain the same 20 questions. Every question is practised in a lab,
and the app's **Exam** page draws a random question with a 3-hour timer and the university marking scheme.
